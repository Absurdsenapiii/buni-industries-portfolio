# Selected projects

## 1. Buni public analytics

**Public evidence:** [source, tests and documentation](https://github.com/Absurdsenapiii/buni-youtube-collector).

A Node.js collector using the YouTube Data API for public channel and video counts. The repository describes the terminal integration, scheduling and data boundaries. Tests use mock data and do not require a live key.

**Status:** active integration documented by the project. This portfolio does not promise uninterrupted operation or independently audit all collected data. Private owner analytics are separate.

## 2. POTTAH! narrative game

**Public evidence:** [game case study and verification record](https://github.com/Absurdsenapiii/buni-game-portfolio).

A Godot/GDScript prototype covering branching story state, save/load recovery, replay-aware behavior, input handling and audio controls.

**Status:** in development. Production media, graphical playthroughs and target-device validation remain open. No finished-game or mobile-store release is claimed.
