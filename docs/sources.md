## Labels used

- **Public artifact:** a repository or document was available to inspect.
- **Project-maintained record:** a first-party statement about a project or its operation.
- **Independent checkpoint review:** specified tests were rerun against a specified development checkpoint. This is not certification of the whole product.
- **In development / historical:** work is unfinished or retained as an archive, rather than presented as a supported release.

Repository creation dates are not necessarily project start dates. Assertion counts and lines of code are not measures of quality, completion or commercial success.
